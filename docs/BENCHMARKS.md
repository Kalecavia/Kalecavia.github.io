## Shared patterns worth adopting

1. Start with a singular visual thesis.
2. Use one controlled interaction grammar.
3. Keep transitions short enough that content remains in charge.
4. Let technology disappear behind responsive, tactile feedback.
5. Treat loading, touch, fallback and audio state as part of art direction.
6. Budget effects: a few high-quality signals beat a page full of shaders.

## Patterns deliberately rejected

- Scroll locking and long unskippable intros.
- Navigation that only exists inside a canvas.
- Mandatory sound.
- Large video loops before meaningful text renders.
- Desktop-only interaction disguised as responsive design.
